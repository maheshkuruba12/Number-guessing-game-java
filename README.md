# Number Guessing Game in Java

A simple command-line game where the player tries to guess a randomly generated number. The game provides hints whether the guessed number is too high or too low until the player guesses correctly.

## Features
- Generates a random number between 1 and 100.
- Prompts the player to enter guesses via the console.
- Provides feedback on whether the guess is too high or too low.
- Tracks the number of attempts made by the player.

## Requirements
- Java Development Kit (JDK) 8 or higher
- A terminal or command-line interface

cd number-guessing-game

## Compile the Java source file:
javac NumberGuessingGame.java

## Usage
Run the game using the following command:
java NumberGuessingGame

## How to Play
Start the game using the command above.
You will be prompted to guess a number between 1 and 100.
Enter your guess and press Enter.
The game will inform you if your guess is too high, too low, or correct.
Continue guessing until you find the correct number.
The game displays the total number of attempts you made.

## Example

Guess a number between 1 and 100: 50

Congratulations! You guessed the number in 3 attempts.
